# DeepZones rank artwork

Public client resource-pack downloads for the DeepZones Minecraft Java server.

The Imperial Insignia pack contains five original miniature emblems: Emperor crown, Lord shield, Duke diamond, Earl jewel and Baron signet. It adds only the `deepzones:ranks` font and its artwork; it does not replace vanilla fonts or textures.

Target: Minecraft Java Edition 1.21.11 (resource-pack format75.0).

This repository contains client artwork only. Server configuration, player records and permission data are not published here.
